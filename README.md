# Celestial Bodies Database
This project is part of the freeCodeCamp Relational Database Certification.

## Description
A PostgreSQL database that stores information about celestial bodies in the universe, including:
- Galaxy
- Star
- Planet
- Moon
- Constellation
The databse demonstrates the use of:
- Primary Keys
- Foreign KEys
- One-to-Many Relationships
- Data Types
- Constraints
- SQL Queries
